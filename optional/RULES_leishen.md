# 可选插件：雷神众测项目接入

> **非主路必经。** 仅当用户明确「接雷神单 / 查雷神项目」且本机已配置对应数据脚本时使用。无脚本则跳过本插件，改由用户粘贴 `testRange` 手工写入 `{output_dir}/scope.txt`。

## 目标

从众测平台拉取**可指认**的授权范围与测试规则，生成：

- `{output_dir}/scope.txt` — 唯一授权域名清单
- `{output_dir}/leishen_rules.md` — 测试红线 / 奖励规则 / 项目状态（效力等同 `RULES_<平台>.md`）

## 建议步骤（实现随用户环境）

1. **列项目**：调用用户自备的列表脚本或 API，展示项目名 / id / 状态 / 时间窗，由用户选定 id
2. **拉详情**：读取 `testRange`（**唯一授权范围**）、`testRule` / `rewardRule` / `progress`
3. **写 scope**：仅将 `testRange`（及已解析附件中的范围内资产）写入 `scope.txt`；未列出的资产（含疑似子域）一律范围外
4. **写规则**：原文落入 `leishen_rules.md`，阶段 8 提交文案按其组织
5. 进入主 `SKILL.md` 阶段 0，后续与普通目标一致

## 护栏

- 脚本路径、agentKey、账号配置**不写进本技能**；由用户本机 config 提供
- `testRange` 未列出 ≠ 可以「看起来像目标」就测
- 项目非进行中 / 未过报名审核 → 如实告知，不开打
- 数据仅供授权测试，勿外泄

## 与主技能关系

本插件只解决「范围从哪来」；测绘与攻击仍听根目录 `SKILL.md`，出门仍过 `skills/pentest-quality-gate`。
